# Lighting & Architectural Package Review — Checklist

Run in order. Each item is either OK or a numbered finding with severity
(Major = code/safety/function, Minor = quality/coordination, Comment = preference).

## 0. Inputs

- [ ] Architectural and ceiling plans (current revision number noted).
- [ ] Furniture/layout plan and interior elevations.
- [ ] Electrical layout, single-line and panel schedule.
- [ ] Lighting layout(s), fixture schedule, photometric files, control narrative.
- [ ] Mechanical layout (diffusers) and fire layout (detectors, sprinklers).
- Log every missing input as a finding at Minor severity or above — never review
  around a missing drawing silently.

## 1. Architecture and ceiling

- [ ] Ceiling heights stated per space, consistent with the interior sections.
- [ ] Ceiling void adequate for the specified recessed fixtures and their drivers.
- [ ] Cove geometry has depth, an upturn and clearance — not a decorative groove.
- [ ] Heavy fixtures (chandelier, fan, cluster) show framing/backing, not board.
- [ ] Fire-rated ceiling assemblies preserved, FR board where required.
- [ ] MR board in wet rooms; no standard board behind a shower.
- [ ] Access panels reach every driver, transformer and control module.
- [ ] Control joints shown on long plaster runs; linear strips do not cross them.
- [ ] Curtain pockets dimensioned, strip located window-side.

## 2. Coordination

- [ ] Downlights not clashing with AC diffusers (≥ ~500 mm) or in the throw.
- [ ] Smoke detectors ≥ 900 mm from supply diffusers, unobstructed.
- [ ] Sprinklers retain coverage; no fixture shadowing a head.
- [ ] Ceiling-mounted sensors, speakers, cameras and alarm devices on the same
      coordinated ceiling plan.
- [ ] Conflicts issued on a marked-up plan, not as prose alone.

## 3. Lighting design quality

- [ ] Every space has ambient + task/accent + decorative as appropriate; a
      single-layer space is flagged.
- [ ] CCT consistent within a space; CRI stated and ≥ 90 where it matters.
- [ ] Glare addressed: UGR, shielding angle, or a stated viewing-position check.
- [ ] Beam angles matched to the task (not one 60° can everywhere).
- [ ] Dimmable ranges real: no luminaire asked to dim below its driver's limit.
- [ ] Wall-washing and art accents positioned to avoid scallops and hotspots.
- [ ] Vertical illuminance considered at mirrors, art, wardrobes, feature walls.

## 4. Numbers

- [ ] Every room has a target lux, a plane and a computed lux.
- [ ] Calculations used MF 0.8 interior / 0.6–0.7 exterior, and said so.
- [ ] Uniformity checked (E_min/E_avg), not only the average.
- [ ] LPD computed on connected load per space and whole villa, compared to the
      cited SBC edition and clause.
- [ ] Emergency/egress lighting present in corridors and stairs per SBC 801 /
      means-of-egress requirements.

## 5. Exterior

- [ ] IP/IK ratings listed per fixture and appropriate to the location.
- [ ] Pool/water SELV + RCD + bonding shown on the electrical drawings.
- [ ] Uplight and glare controlled; nothing aimed at neighbouring windows.
- [ ] Fixture mountings and aiming shown (a facade wash needs an aim, not a tag).
- [ ] Drainage and cleaning access for in-ground and boundary fixtures.
- [ ] Climate derating (45–50 °C, dust, coastal corrosion) reflected in the spec.

## 6. Schedule integrity

- [ ] Bidirectional match: every tag on the plan is in the schedule; every
      schedule row appears on a plan.
- [ ] Each row complete: tag, maker, model, W (input), lm, CCT, CRI, beam,
      cut-out/can depth, IP/IK, driver, dimming protocol, mounting, qty.
- [ ] Quantities cross-checked against the plan count.
- [ ] Local availability flagged — a fixture with no KSA distributor is a
      procurement finding, not a design finding.

## 7. Output

- [ ] Findings report: numbered, severity-tagged, each with the drawing reference
      and the fix requested.
- [ ] Anything unverifiable is listed as "requires the photometric file / calc"
      rather than passed or failed silently.
- [ ] Mock-up and commissioning items listed (aim, scene set-up, lux measurement
      at handover, control system programming).
