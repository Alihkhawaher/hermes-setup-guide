# Illuminance Targets — Villa Interior & Exterior

Maintained horizontal illuminance (lux) on the stated plane, IES/CIBSE practice.
Treat as targets to confirm, not code text.

## Interior

| Space | Target lux | Plane | Notes |
|---|---|---|---|
| Living room (general) | 100–150 | 0.75 m | layer with accent; dimmable |
| Living room (reading) | 300–500 | task | local task light, not ceiling-only |
| Majlis / formal sitting | 100–200 | 0.75 m | warm 2700 K, high CRI for fabrics |
| Dining (general) | 100–150 | 0.75 m | pendant or linear over the table |
| Dining table (task) | 300 | table top | 300–400 for hosting |
| Kitchen general | 200–300 | 0.85 m | avoid shadow on counter |
| Kitchen counter / prep | 400–500 | counter top | under-cabinet strip, CRI ≥ 90 |
| Bedroom general | 50–100 | 0.75 m | dimmable, no glare at bed head |
| Bedroom reading | 300 | task | asymmetric or swing-arm |
| Bathroom general | 150–200 | floor + 0.1 m | vertical mirror light 300–500 at face |
| Bathroom mirror (vertical) | 300–500 | face | light both sides of a mirror, not above only |
| Corridor / stairs | 50–100 | floor | motion + low-level; nosing detail in stairs |
| Entrance / foyer | 150–200 | floor | transition to exterior brightness |
| Wardrobe interior | 200–300 | shelf | CRI ≥ 90 |
| Home office | 300–500 | desk | screen-glare control |
| Kids' room | 150–300 | 0.75 m | higher end of range |
| Laundry / utility | 200–300 | 0.85 m | IP44 minimum |
| Garage | 100–200 | floor | IP44, IK08 housings |

## Exterior

| Zone | Target lux | Notes |
|---|---|---|
| Main entrance door | 100–200 | welcome level, shielded downlight |
| Pedestrian path / walkway | 20–50 | low bollards, warm |
| Steps and level changes | 50–100 | mandatory legibility; contrast the nosing |
| Driveway | 30–50 | avoid spill to neighbours |
| Car park / garage apron | 50–100 | uniformity matters more than peak |
| Garden / planting accent | 50–100 on the object | grazing for walls, uplight for trees |
| Water feature / pool surround | 20–50 | see exterior file for electrical rules |
| Terrace / seating | 50–100 | 2700 K, insect-friendly warm if asked |
| Facade wash | 10:1–30:1 lit:unlit contrast | not a lux target — a contrast target |
| Perimeter / security | 50 | combined with CCTV, not instead of it |

## Colour, rendering and glare

- CCT: 2700 K throughout residential, 3000 K acceptable in kitchens/utility and
  in outdoor areas. Avoid 4000 K+ indoors except garages/utility.
- CRI ≥ 90 interior (R9 ≥ 50 where skin tones, wood, fabrics matter), CRI ≥ 80
  acceptable outdoors.
- Glare: UGR ≤ 19 in general residential rooms, ≤ 16 at desks and above seating;
  shielding so the lamp is not visible from a seated or lying position.
- Uniformity: general lighting E_min/E_avg ≥ 0.4 indoors; outdoor paths need
  legibility, not just a good average — check the worst point.
- Flicker: dimmable drivers, ripple < 5 %, no visible flicker at the lowest dim
  scene; verify at commissioning, not on a spec sheet.
